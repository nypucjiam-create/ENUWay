# ЛЗ №12 — ENUWay AI бағалау жинағы

Бұл бума ENUWay қолдау өтініштерін бес санатқа жіктейтін функцияны тексеруге арналған.

## Құрамы

- `dataset.jsonl` — 40 қолмен құрастырылған және бағаланатын модельге берілмей эталон санаты бекітілген өтініш; оның ішінде 10 күрделі мысал бар.
- `run_eval.py` — 20 кілтсөздік ережеден тұратын базалық тәсілді және жергілікті модельдің zero-shot/few-shot нұсқаларын өлшейді.
- `results/metrics.json` — accuracy, macro F1 және әр санаттың precision/recall/F1 көрсеткіштері.
- `results/*_raw.jsonl` — модельге берілген нақты промпттар, өңделмеген жауаптар, токендер және кідіріс.
- `results/error_analysis.csv` — мысалдар бойынша салыстыру және қате талдауы.

## Қайта іске қосу

Базалық тәсіл:

```powershell
python evals/lz12/run_eval.py
```

OpenAI-үйлесімді жергілікті сервер іске қосылғанда:

```powershell
python evals/lz12/run_eval.py --server-url http://127.0.0.1:8080 --model qwen2.5-3b-instruct-q4_k_m.gguf
```

Өлшеу параметрлері: `temperature=0`, `seed=42`, жауап ұзындығы — 4 токенге дейін. Few-shot промптында әр санатқа екіден, барлығы 10 мысал берілген. Эталондар бағаланатын модельдің жауабынан алынбайды. Деректер оқу үшін құрастырылған, нақты пайдаланушылардың дербес деректері жоқ.

Модель көзі: <https://huggingface.co/Qwen/Qwen2.5-3B-Instruct-GGUF>. `qwen2.5-3b-instruct-q4_k_m.gguf` файлының SHA-256 бақылау сомасы: `626b4a6678b86442240e33df819e00132d3ba7dddfe1cdc4fbb18e0a9615c62d`.
