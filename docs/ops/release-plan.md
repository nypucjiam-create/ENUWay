## Релиз чек-листі

- [ ] Релиз көлемі мен жауапты адам бекітілді.
- [ ] Pull request мақұлданды, CI жасыл.
- [ ] Қамту 60%-дан төмен емес.
- [ ] Trivy және gitleaks блоктайтын finding таппады.
- [ ] Дерекқор өзгерісі болса, кері үйлесімділік тексерілді.
- [ ] Тест деректері жасанды және жеке дерек жоқ.
- [ ] Smoke-тест: `/health`, іздеу, сапар құру, броньдау.
- [ ] Релиз артефакты мен commit SHA жазылды.
- [ ] Тапсырыс берушіге өзгерістер мен белгілі шектеулер жіберілді.
- [ ] 30 минуттық кейінгі бақылау аяқталды.

## Кері қайтару чек-листі

1. **Кері қайтару туралы шешімді Альфараби 10 минут ішінде жеке қабылдайды.**
2. Триггерлер: health-check екі рет өтпеді; бронь жоғалды не екі рет жазылды; қате үлесі 5%-дан асты; қауіпсіздік тәуекелі анықталды.
3. Ағымдағы релиз SHA және алдыңғы жасыл SHA жазылады.
4. Жаңа өзгерістер тоқтатылып, командаға және тапсырыс берушіге хабар беріледі.
5. Алдыңғы жасыл артефакт қайта жарияланады немесе revert PR біріктіріледі.
6. `/health` және негізгі үш сценарий қайта тексеріледі.
7. 30 минут мониторинг жүргізіледі.
8. Инцидент ашылып, 48 сағат ішінде postmortem дайындалады.
