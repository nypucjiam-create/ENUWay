## Состав работы

Работа содержит матрицу из 11 стейкхолдеров, план коммуникаций и правило накопления рабочих вопросов, модельные протоколы интервью с представителем заказчика и пользователя, story map со сквозным MVP, 18 историй в GitHub Issues, проверку INVEST и 18 измеримых нефункциональных требований.

## Допущения

Числовые пороги НФТ и story point являются проектными допущениями учебного прототипа. Перед пилотом они согласуются с заказчиком. Модельные интервью не выдаются за ответы реальных респондентов и должны быть заменены фактическими записями после проведения интервью.

## Использование ИИ

OpenAI Codex использован для подготовки черновой структуры, таблиц и вариантов формулировок. Команда отвечает за проверку требований, числовых допущений и соответствие содержимого GitHub Issues фактическим решениям проекта.
