# Командаға арналған пайдалану нұсқаулығы

## Мақсаты

Ассистент екі өткен спринттің GitHub дерегінен апталық статус-есеп черновигін жасайды. Ол шешім қабылдамайды және есепті өзі жарияламайды.

## Іске қосу

1. Компьютерде Ollama орнатып, `ollama pull qwen2.5:0.5b` командасымен модельді дайындау.
2. Репозиторий түбірінде `python scripts/pm_status_assistant.py` орындау.
3. Нәтижені `docs/pm-assistant/run/` бумасынан ашу.
4. `source-data.json` пен GitHub сілтемелері арқылы барлық санды, күнді және атауды тексеру.
5. Қателерді `verification-log.csv` журналына енгізіп, тек содан кейін есепті бөлісу.

GitHub Actions дүйсенбі сайын 03:15 UTC-де және қолмен іске қосылғанда дәл осы сценарийді орындайды. Жасалған файл автоматты түрде жарияланбайды, тек жүктелетін artifact ретінде сақталады.

## Сыртқы модельге жіберуге тыйым салынған деректер

- ЖСН, телефон, жеке e-mail, нақты маршрут және геолокация;
- GitHub токені, құпиясөз, API кілті, cookie және session идентификаторы;
- тапсырыс берушінің жарияланбаған коды немесе құжаты;
- коммерциялық құпия, келісімшарт сомасы және қолжетімділігі шектелген ақпарат;
- рұқсатсыз студент немесе қызметкер туралы бағалау.

Құпия дерек қажет болса, сыртқы сервис қолданылмайды: дерек иесінен рұқсат алынады немесе жергілікті модельге де жіберілмей, қолмен өңделеді.

## Міндетті бақылау

PM әр сан мен сілтемені тексереді, модельдің қорытындысын факт ретінде қабылдамайды және жарияланған құжат үшін өзі жауап береді. Қате жоқ деген журнал жасауға болмайды: табылған қате толық жазылады.
