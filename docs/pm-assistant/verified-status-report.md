# ENUWay жобасының тексерілген статус-есебі

**Дерек көзі:** GitHub REST API, `nypucjiam-create/ENUWay` репозиторийінің `main` тармағы.  
**Дерек жиналған уақыт:** 26.11.2026.  
**Мәртебе:** PM қолмен тексерген нұсқа.

## Қысқаша қорытынды

Екі өткен спринтте негізгі тармаққа барлығы 13 коммит түсті: бірінші спринтте 3, екінші спринтте 10. Екінші спринттегі коммит саны 7-ге артқан. Бұл жұмыс белсенділігінің өскенін көрсетеді, бірақ коммит саны жеткізілген пайдаланушы құндылығын өздігінен дәлелдемейді.

## Спринт 1

Кезеңі: 16.09.2026 00:00 UTC–30.09.2026 00:00 UTC аралығы, соңғы шекара есепке кірмейді. GitHub API үш коммит қайтарды. Коммиттер ENUWay жұмыс кеңістігін бастапқы дайындауға, GitHub сілтемелерін қосуға және шешім күнін нақтылауға қатысты.

## Спринт 2

Кезеңі: 30.09.2026 00:00 UTC–14.10.2026 00:00 UTC аралығы, соңғы шекара есепке кірмейді. GitHub API он коммит қайтарды. Негізгі нәтижелер ЛЗ 4 талаптар пакетін, ЛЗ 5 жеткізу жоспарын және ЛЗ 6 Монте-Карло болжамын дайындау мен әдістемеге сәйкестендіруге қатысты.

## Ашық мәселелер және тәуекелдер

Жинау сәтінде репозиторийде 38 issue болды: 37 ашық және 1 жабық. Ашық мәселелердің 28-інде орындаушы, 18-інде белгі жоқ. Бұл жоспарлау кезінде жауапкершіліктің көрінбеуі және басымдықты сүзудің қиындауы тәуекелін тудырады. Скрипт issue мәтінінде нақты блоктаушы байланыс көрсетілмесе, «блокталған» мәртебесін ойдан қоспайды.

## Келесі әрекеттер

1. Ашық 28 тапсырмаға нақты орындаушы тағайындау.
2. Белгісі жоқ 18 тапсырмаға кемінде жұмыс түрі мен басымдық белгісін беру.
3. Келесі автоматты есепте коммит санымен қатар жабылған issue және қабылданған pull request санын бөлек көрсету.
4. Жариялау алдында әр санды `source-data.json` файлымен және GitHub сілтемесімен тексеру.

**Ескерту:** бұл нұсқа модель мәтінін автоматты түрде жарияламайды. Соңғы құжат үшін жауапкершілік PM-де қалады.
