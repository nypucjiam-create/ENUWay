# Сапа мен уақытты өлшеу

## Нақты орындалған өлшем

- Жергілікті Qwen2.5 3B моделінің мәтін генерациясы: **507,713 секунд**.
- GitHub API дерегін алу және файлдарды толық жазу: **510,613 секунд**.
- Он бақылау нүктесін қолмен тексеру: **50 секунд**.
- Қате немесе толық емес бақылау нүктелері: **7/10 = 70%**.

Қате үлесі тек жалған сандарды емес, тапсырмада міндетті болған, бірақ модель өткізіп кеткен бөлімдерді де қамтиды. Сондықтан көрсеткіш модельдің жариялауға дайын есеп беру сапасын бағалайды.

## Уақыт үнемі

Тексерілген есепті бастапқы JSON-нан қолмен құрастырудың осы жұмыс барысындағы бақылау уақыты: **80,52 секунд**. Толық ИИ жолы: 510,613 + 50 = **560,613 секунд**. Таза нәтиже: 80,52 − 560,613 = **−480,093 секунд**, яғни осы компьютердегі 3B модель уақыт үнемдемеді.

Қауіпсіз резервтік есеп модельсіз **2,807 секундта** құрылды. Оны 50 секунд тексергенде толық уақыт 52,807 секунд, бақылау қол еңбегіне қарағанда **27,713 секунд үнемдейді**. Сондықтан ұсынылған өндірістік шешім — фактілер мен сандарды детерминирленген кодпен құру, ал ИИ-ді тек қысқа мәтінді өңдеуге қолдану. GitHub Actions-тағы 0,5B модельдің жылдамдығы бөлек өлшенбейінше, оған үнем туралы уәде берілмейді.
