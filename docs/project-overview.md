# ENUWay жобасының қысқаша сипаттамасы

## Өнімдік болжам

Егер ENU студенттері мен қызметкерлері тексерілген ортада бағыт, уақыт және бос орын бойынша бірін-бірі тез таба алса, университетке қатынау арзанырақ әрі қолайлы болады.

## Нысаналы пайдаланушылар

- университетке жеке көлікпен қатынайтын ENU студенттері мен қызметкерлері;
- сол бағытта жолаушы ретінде қосылғысы келетін ENU қауымдастығының мүшелері;
- пилоттың қауіпсіздігі мен шағымдарды өңдеуге жауапты модератор.

## MVP құрамына кіреді

- ENU пайдаланушысын тексеру;
- сапар құру және сапарға қосылу;
- бағыт, уақыт, бос орын және болжамды шығынды көрсету;
- броньнан бас тарту;
- рейтинг, шағым, бұғаттау;
- модераторға арналған қарапайым бақылау.

## MVP құрамына кірмейді

- қосымша ішіндегі төлем;
- такси диспетчерлеу;
- толық навигация;
- сапардың міндетті түрде орындалуына кепілдік;
- сақтандыру және төтенше жағдай қызметін алмастыру.

## Негізгі тәуекел

Пайдаланушыны тексеру немесе шағымды өңдеу әлсіз болса, сенім жоғалып, пилот тоқтауы мүмкін. Сондықтан қауіпсіздік талаптары әр итерациядағы release gate ретінде қаралады.
