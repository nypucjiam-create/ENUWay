## Колонка сипаттамалары

- **Ready:** DoR толық орындалған, бастауға дайын жұмыс;
- **In Progress:** белсенді орындалатын жұмыс, әр адамға 2 және командаға 6 шегі бар;
- **Waiting:** кедергі иесі мен қайта тексеру күні міндетті;
- **Review:** екінші команда мүшесінің тексеруі, DoD толық болса ғана Done күйіне өтеді.

Тақтадағы Done карточкаларының тарихи қозғалысы сақталмағандықтан, екі өткен спринттің метрикалары Git commit дәлелдері арқылы ретроспективті түрде қалпына келтірілді. Келесі спринттерде карточка әр нақты ауысқан күні қозғалады.
