# ENUWay DoR және DoD

## Definition of Ready

Карточка Ready күйіне тек келесі шарттардың барлығы орындалғанда өтеді:

- пайдаланушы немесе тапсырыс беруші үшін күтілетін нәтиже бір сөйлеммен жазылған;
- қабылдау критерийлері өлшенетін және тексерілетін түрде берілген;
- жұмыс көлемі команда түсінетіндей бөлінген және бағаланған;
- тәуелділіктер, сыртқы шешімдер және қажетті қолжетімділіктер көрсетілген;
- басымдық, спринт, жауапты адам және қажетті меткалар қойылған;
- құпия дерек, қауіпсіздік немесе сәйкестік тәуекелі болса, тексеру тәсілі жазылған;
- орындауды бастауға кедергі жоқ.

Бір шарт орындалмаса, карточка Backlog күйінде қалады.

## Definition of Done

Карточка Done күйіне тек келесі шарттардың барлығы орындалғанда өтеді:

- барлық қабылдау критерийлері орындалған және дәлелі карточкаға тіркелген;
- тиісті тесттер орындалған, нәтиже сәтті және қайта өндіріледі;
- нәтижені тапсырманы орындамаған екінші команда мүшесі тексерген;
- нәтиже қолжетімді стендте, прототипте немесе репозиторийдегі ашылатын артефакт түрінде көрсетіледі;
- құжаттама, сілтемелер және өзгеріске қатысты нұсқаулық жаңартылған;
- қауіпсіздік пен дербес деректерге әсері тексерілген;
- ашық ақау немесе шешілмеген блокер жоқ;
- карточкадағы нақты аяқталу күні мен дәлел сілтемесі толтырылған.

Done күйіндегі нәтиже бұрынғы күйге қайтарылмайды. Кейін өзгеріс қажет болса, бастапқы карточкаға байланыстырылған жаңа тапсырма ашылады.
