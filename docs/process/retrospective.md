# ENUWay екі спринтінің ретроспективасы

## Спринт 1 ретроспективасы

**Күні:** 29.09.2026.  
**Қатысушылар:** Альфараби, Нурай, Нурислам.  
**Формат:** Continue, Stop, Start.

**Continue:** нәтижені Git commit және репозиторийдегі ашылатын файл арқылы дәлелдеу. Бұл тәсіл орындалған жұмыстың уақытын кейін тексеруге мүмкіндік берді.

**Stop:** бірнеше түрлі нәтижені бір үлкен жұмыс ретінде қарастыру. Мұндай тәсіл throughput-ты төмен көрсетіп, нақты аяқталған бөліктерді жасырды.

**Start:** ірі пакетті жеке қабылданатын нәтижелерге бөлу және әр нәтижені бөлек аяқтау дәлелімен жабу.

## Қабылданған әрекет

**Әрекет:** Спринт 2 жұмысын кемінде үш бөлек қабылданатын нәтижеге бөлу және әрқайсысын жеке соңғы commit-пен жабу.  
**Иесі:** Альфараби.  
**Мерзімі:** 13.10.2026.  
**Өлшемі:** спринт соңында кемінде 3 бөлек аяқталған жұмыс элементі және әр элементке start/finish commit сілтемесі болуы тиіс.

## Спринт 2 ретроспективасы

**Күні:** 13.10.2026.  
**Нәтиже:** үш бөлек нәтиже дәлелденді: ЛЗ 4 талаптар пакеті, ЛЗ 5 жеткізу жоспары және ЛЗ 6 ықтималдық болжамы. Throughput 2-ден 3 элементке өсті. Орташа cycle time 6,99 сағаттан 1,25 сағатқа, p85 11,62 сағаттан 2,17 сағатқа төмендеді.

Метрикалардың жақсаруы тек қабылданған әрекеттен болды деп айтуға болмайды: жұмыс элементтерінің көлемі әртүрлі, ал board transition тарихы сақталмаған. Дегенмен жұмыс пакеттерін бөлу аяқталған нәтижелерді жеке санауға және олардың дәлелін нақты көрсетуге мүмкіндік берді.

## Ретроспектива қорытындысы

Әрекет өлшемі орындалды: Спринт 2-де 3 бөлек аяқталған элемент бар. Келесі спринттерде карточкалар нақты күні жылжытылып, Ready, Waiting және Review күйлерінің уақыты GitHub Projects арқылы тікелей өлшенеді.
