## Ашық шектеу

GitHub Projects тақтасында өткен спринттердің Done карточкалары және кезең ауысу тарихы сақталмаған. Сондықтан Ready және Review уақыты ойдан толтырылмады, ал In Progress пен Done шекаралары нақты Git commit дәлелдерімен қалпына келтірілді. Келесі спринттерде толық экспорт алу үшін карточка әр ауысқан күні жылжытылады.
