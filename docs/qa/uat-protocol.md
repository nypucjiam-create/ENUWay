# ENUWay UAT қабылдау хаттамасы

## Сессия деректері

- **Күйі:** сыртқы сессияға дайын; төмендегі нәтиже — ішкі dry run.
- **Жоспарланған сыртқы UAT:** 13.11.2026, 14:00–14:40.
- **Инкремент:** іздеу, сапар құру және броньдау.
- **Әзірлеуші бақылаушылары:** Альфараби, Нурай, Нурислам.
- **Сыртқы тапсырыс беруші өкілдері:** қорғауға дейін нақты қатысушылармен толтырылады.
- **Ереже:** әзірлеушілер қадамды көрсетпейді; тек уақыт пен ескертуді жазады.

## Сценарийден тыс ескертулер

1. Демо бетінде сапар құру нысаны жоқ; API арқылы ғана тексеріледі — P2.
2. Бронь расталғаннан кейін жолаушыға сапар мәліметін қайта көрсету керек — P3.

## Қабылдау шешімі

Ішкі dry run бойынша инкремент **шартты түрде дайын**: UAT-10 P1 түзетілмей және сыртқы команда UAT өткізбей толық қабылданбайды. Сыртқы сессиядан кейін осы бөлім «қабылданды / қабылданбады / шартты қабылданды» шешімімен, қатысушылармен және нақты GitHub issue сілтемелерімен жаңартылады.
