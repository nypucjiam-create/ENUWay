## Міндетті сыртқы қадам

UAT сценарийлері мен хаттама дайын, бірақ әдістеме бойынша қабылдауды ENUWay әзірлеушілері емес, басқа команда немесе нақты тапсырыс беруші өткізуі керек. Репозиторийдегі алдын ала нәтиже ішкі dry run ретінде белгіленген; қорғауға дейін сыртқы қатысушылардың аты, күні және қолы немесе растайтын хабарламасы қосылады.

## Мониторинг

Docker қолжетімді ортада Uptime Kuma қолданылады. Docker daemon жоқ кезде әдістеме рұқсат ететін балама ретінде `.github/workflows/availability.yml` әр 6 сағат сайын репозиторий қолжетімділігін тексереді. Нақты стенд URL пайда болғанда сол URL-ге ауыстырылады.
