## Факторлар

1. Workflow сыртқы GitHub Action тегінің бар-жоғын pull request кезеңінде тексермеді.
2. Пайплайн бірнеше қадаммен бірден енгізілді, сондықтан келесі ақау алдыңғысы түзетілгеннен кейін ғана көрінді.
3. Локалдық Windows іске қосылымы жұмыс каталогын Python import жолына қосты, ал Linux CI ортасы оны автоматты қоспады.
4. Репозиторийдегі бұрынғы Word-тест `python-docx` тәуелділігін талап етті, бірақ жаңа runtime requirements тізімінде ол бастапқыда болмады.
5. Негізгі тармақта міндетті CI ережесі пайплайннан бұрын қосылмаған.

## Не сработало

- GitHub Actions annotation action тегінің қатесін журнал ашпай-ақ көрсетті;
- әр түзету жеке commit болғандықтан хронология мен lead time дәл сақталды;
- автоматты тесттер бизнес ережелерін тексеріп, жасыл run-да 89% қамту көрсетті;
- DORA скрипті run тарихын қолмен ойдан шығармай API-дан қайта есептеді;
- артефакт тек барлық қақпа өткеннен кейін жарияланды.
