# Командалық жұмыс келісімдері

## Тапсырма атауы

`[ENU-###] Етістік + нәтиже`

Мысал: `[ENU-005] Сапар құру ағынын прототиптеу`.

## Branch атауы

`type/ENU-###-short-description`

Рұқсат етілген type: `feature`, `fix`, `docs`, `chore`, `spike`.

Мысал: `feature/ENU-005-create-ride-flow`.

## Commit

`type(scope): қысқа сипаттама [ENU-###]`

Мысал: `feat(ride): сапар құру формасын қосу [ENU-005]`.

## Pull request

`ENU-###: Нәтиженің қысқа атауы`

PR кемінде бір басқа команда мүшесінің review-ынан кейін ғана біріктіріледі. `main` тармағына тікелей push жасалмайды.

## Definition of Ready

- мақсат пен пайдаланушы құндылығы түсінікті;
- acceptance criteria жазылған;
- тәуелділіктер мен тәуекелдер белгіленген;
- estimate және owner бар.

## Definition of Done

- acceptance criteria орындалды;
- қажетті тест немесе тексеру дәлелі тіркелді;
- құжаттама жаңартылды;
- құпиялық және қауіпсіздікке әсері тексерілді;
- review аяқталды және жұмыс `main` тармағына біріктірілді;
- demo-да көрсетуге дайын.

## Коммуникация

- аптасына бір рет backlog refinement;
- аптасына бір рет demo және кері байланыс;
- blocker бір жұмыс күні ішінде тақтада белгіленеді;
- маңызды архитектуралық немесе басқарушылық шешім ADR арқылы тіркеледі.
