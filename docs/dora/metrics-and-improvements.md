# ENUWay DORA анықтамалары және жақсарту жоспары

## Өлшеу ережелері

1. **Жариялау** — `main` тармағындағы CI толық өтіп, нұсқаланған `enuway-<commit>.tar.gz` артефакты GitHub Actions ішінде жарияланған сәт.
2. **Жеткізу уақыты** — commit уақыты мен сол commit үшін сәтті CI аяқталған уақыттың айырмасы.
3. **Сәтсіз өзгеріс** — `main` тармағындағы CI сәтсіз аяқталған немесе 24 сағат ішінде түзету не кері қайтару қажет болған өзгеріс.
4. **Қалпына келу уақыты** — сәтсіз CI аяқталған сәттен кейінгі бірінші сәтті CI аяқталғанға дейінгі уақыт. Пайдаланушылық инциденттер бөлек журналда тіркеледі.

Бұл анықтамалар оқу стендіне арналған. Өндірісте жариялау қолданушыға қолжетімді ортаға жеткізумен өлшенеді.

## Түсіндіру

Төрт көрсеткіш те репозиторийдің нақты тарихынан алынады. Оннан аз бақылау болғанда командаға жоғары немесе төмен деңгей беру дұрыс емес; ағымдағы деңгей — **бастапқы бақылау, дерек жеткіліксіз**. Сандық мәндер `data/dora-metrics.json` файлы жаңартылған сайын қайта есептеледі.

## Сенімділік capacity

Алғашқы төрт аптада команданың 15% capacity-і CI, тесттер, мониторинг және техникалық қарызға бөлінеді. Қайта өлшеуде сәтсіз өзгеріс үлесі 20%-дан асса, үлес уақытша 25%-ға көтеріледі; екі қатарлы өлшеуде 10%-дан төмен болса, 10%-ға қайтарылады.
