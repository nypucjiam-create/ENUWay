# Негізгі тармақ және review саясаты

## Main тармағы

- `main` тармағына тікелей push жасалмайды;
- өзгеріс pull request арқылы енгізіледі;
- кемінде бір қатысушының мақұлдауы керек;
- `CI / quality-gate` тексеруі міндетті;
- жаңа commit жіберілгенде ескі approval жойылады;
- шешілмеген review талқылауы бар PR біріктірілмейді;
- тармақтың өмірі үш күннен аспайды; үлкен жұмыс кішірек тәуелсіз өзгерістерге бөлінеді.

## Review жауапкершілігі

- автор acceptance criteria мен тексеру дәлелін көрсетеді;
- reviewer кодты, қауіпсіздікті, тестті және құжаттаманы қарайды;
- дербес дерекке, аутентификацияға немесе броньға әсер ететін өзгеріс risk review алады;
- emergency өзгерісінен кейін 24 сағат ішінде кейінгі review өткізіледі.
