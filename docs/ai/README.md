# ЛЗ №12 — ENUWay AI бағалау пакеті

Бұл бума ENUWay қолдау өтініштерін AI көмегімен санаттау гипотезасының толық дәлел пакетін жинайды.

## Нәтиже

| Тәсіл | Accuracy | Macro F1 |
|---|---:|---:|
| 20 ережелік baseline | 0,625 | 0,757 |
| Zero-shot Qwen2.5-3B | 0,325 | 0,295 |
| Few-shot Qwen2.5-3B | 0,450 | 0,412 |

Қабылдау шегі (`macro F1 ≥ 0,85`, әр санат `F1 ≥ 0,75`, `SAFETY recall ≥ 0,90`) орындалмады. ADR-004 бойынша AI нұсқасы әзірге енгізілмейді; baseline сақталады және модель/промпт жақсарғаннан кейін дәл сол eval қайта іске қосылады.
