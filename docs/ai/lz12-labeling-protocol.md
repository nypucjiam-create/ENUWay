# Эталондарды дайындау хаттамасы

## Дерек көзі

Бағалау мысалдары ENUWay-дың қолданыстағы талаптары, story map және GitHub backlog-тағы тіркелгі, іздеу, сапар жариялау, бронь және қауіпсіздік сценарийлеріне сүйеніп қолмен құрастырылды. Нақты пайдаланушы хабарламалары көшірілмеді; дербес деректер жоқ.

## Эталонды бекіту ережесі

Әр мәтінге бір негізгі ниет таңдалады. Эталонды анықтау кезінде бағаланатын Qwen моделі қолданылмайды. Шекаралық жағдайда пайдаланушыға бірінші кезекте қай команда жауап беруі тиіс деген қағида басым:

- кіру және профиль — `ACCOUNT`;
- сапар табу — `SEARCH`;
- жүргізушінің өз жарияланымы — `RIDE_MANAGEMENT`;
- жолаушының орны — `BOOKING`;
- қауіп, шағым немесе деректің таралуы — `SAFETY`.

## Сапаны бақылау

Жинақта әр санатқа 8 мысалдан, барлығы 40 мысал бар. Оның 10-ы `hard`: қысқа, аралас тілдегі немесе контексті аз өтініш. Қорытынды тапсыру алдында команда мүшелері алтын белгілерді дербес қарап, келіспеген мысалдарды хаттамаға енгізуі тиіс; бағаланатын модель эталон төрешісі болмайды.
