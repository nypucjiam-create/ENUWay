# ЛЗ №12 — пайдалану құнының есебі

**Есеп күні:** 19.11.2026  
**Нақты өлшем:** 40 few-shot сұрауы, llama.cpp берген Qwen2.5 tokenizer статистикасы  
**Ақылы сервис:** іске қосылған жоқ

## Өлшенген токендер

- кіріс: 25 971 токен, орташа 649,27 токен/сұрау;
- шығыс: 80 токен, орташа 2 токен/сұрау.

## API баламасы

Салыстыру үшін `gpt-6-luna` стандарт тарифі қолданылды: кіріс — $0,10/1 млн токен, шығыс — $0,50/1 млн токен. Ресми баға: <https://developers.openai.com/api/docs/pricing>, қол жеткізу күні 19.11.2026.

Формула:

`сұрау саны × (орташа кіріс токені × кіріс тарифі / 1 000 000 + орташа шығыс токені × шығыс тарифі / 1 000 000)`

- бір сұрау: **$0,00006593**;
- 3 000 сұрау/ай: **$0,1978**;
- 30 000 сұрау/ай (10×): **$1,9778**.

## Self-hosted баламасы және теңесу нүктесі

Есептік нұсқа — Hetzner CPX32, Germany/Finland, IPv4-сыз, ҚҚС-сыз: **$41,99/ай**. Ресми тариф: <https://docs.hetzner.com/general/infrastructure-and-availability/price-adjustment/>, қол жеткізу күні 19.11.2026.

Теңесу нүктесі: `41,99 / 0,00006593 = 636 912 сұрау/ай`.

Бұл тек сервер тарифі бойынша салыстыру; әкімші еңбегі, резерв және мониторинг кірмейді. Ағымдағы оқу eval-ы бар ноутбукте тегін орындалды. Шағын жүктемеде API есептік жағынан арзан, бірақ сыртқы провайдерге дерек беру бөлек құпиялылық шешімін талап етеді.
