# ЛЗ №12 — AI тәуекел карточкасы

**Функция:** қолдау өтінішін санаттау  
**Тәуекел деңгейі:** орташа; `SAFETY` үшін жоғары әсер  
**Иесі:** Нурай  
**Қайта қарау:** пилоттан кейін немесе модель/промпт өзгерген сайын

| Тәуекел сұрағы | ENUWay шешімі |
|---|---|
| Модель қателессе не болады? | Өтініш қате кезекке түсіп, жауап кешігуі мүмкін. `SAFETY` өтінішін өткізіп алу ең қауіпті жағдай болып саналады. |
| Ең нашар салдар | Қауіпсіздік сигналы қарапайым іздеу немесе бронь мәселесі болып белгіленіп, жедел әрекет кешігеді. |
| Қате қалай анықталады? | Әр санат бойынша F1 және `SAFETY recall` апта сайын өлшенеді; оператор санатты өзгерткен оқиға журналға жазылады; бір аптада түзету үлесі 10%-дан асса триггер іске қосылады. |
| Адам қай жерде қатысады? | `SAFETY`, `UNCERTAIN` және оператордың сенімсіз деп белгілеген барлық өтінішін адам тексереді. AI ешбір аккаунтты, броньды немесе шағымды өздігінен өзгертпейді. |
| Пайдаланушы не көреді? | «Өтініш AI көмегімен алдын ала санатталды» белгісі, таңдалған санат және «Адамға жіберу» батырмасы көрсетіледі. |
| Провайдерге қандай дерек кетеді? | Әдепкі шешімде сыртқы провайдер жоқ: модель жергілікті ортада іске қосылады. Болашақ API нұсқасында тек бүркемеленген мәтін жіберіледі; аты-жөні, телефон, пошта, көлік нөмірі және сапар ID жіберілмейді. |
| Модель қолжетімсіз болса не болады? | Жүйе 20 ережелік baseline-ға ауысады; сәйкестік болмаса өтініш `UNCERTAIN` ретінде жалпы кезекке түседі. Негізгі ENUWay функциялары тоқтамайды. |
| Әділетсіздік тәуекелі | Қазақша, орысша және аралас тілдегі күрделі мысалдар бөлек бақыланады. Тілдер арасындағы қате айырмасы 10 пайыздық тармақтан асса пилот тоқтатылады. |
| Prompt injection | Өтініш тек жіктеледі, онда жазылған бұйрықтар орындалмайды. Шығыс тек рұқсат етілген алты белгінің біріне нормалданады. |

## Бақылау триггерлері

- `SAFETY recall < 0,90` — автоматты санаттауды дереу тоқтату, иесі: Альфараби.
- Жалпы операторлық түзету үлесі `> 10%` — қателерді талдап, промптты қайта тексеру, иесі: Нурай.
- Модельдің p95 жауабы `> 2 секунд` немесе қолжетімділігі `< 99%` — baseline-ға ауысу, иесі: Нурислам.
- Дербес дерек шикі журналдан табылды — журналды оқшаулау, қауіпсіздік оқиғасын ашу, иесі: Нурислам.
