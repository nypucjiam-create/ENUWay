# ADR-004: ENUWay қолдау өтініштерін AI көмегімен санаттау

- **Күйі:** қабылданды — AI нұсқасын әзірге енгізбеу
- **Күні:** 19.11.2026
- **Шешім иесі:** Альфараби
- **Қайта қарау күні:** 19.12.2026 немесе 500 пилоттық өтініштен кейін

## Контекст

Қолдау өтінішін қолмен кезекке бөлу уақыт алады, ал кілтсөздер аралас тілді, қысқа және астарлы өтініштерді толық ажыратпайды. Сонымен бірге AI қатесі қауіпсіздік өтінішін кешіктіруі мүмкін. Шешім сапа, құпиялылық, қайтымдылық және шығын бойынша тексерілуі тиіс.

## Қаралған нұсқалар

1. **Тек 20 кілтсөздік ереже.** Арзан әрі түсінікті, бірақ мағыналық вариацияны нашар ұстайды.
2. **Сыртқы API моделі.** Масштабтау оңай, бірақ мәтін үшінші тарапқа жіберіледі және тұрақты операциялық шығын бар.
3. **Жергілікті Qwen2.5-3B-Instruct Q4_K_M.** Төлемсіз өлшеуге болады, дерек құрылғыдан шықпайды, бірақ сервер ресурсы мен мониторинг қажет.
4. **RAG.** Білім базасынан жауап құруға ыңғайлы, бірақ бұл міндетте жауап емес, жабық санаттар жіктеледі; күрделілігі артық.

## Шешім

Ағымдағы Qwen2.5-3B-Instruct few-shot нұсқасын ENUWay пилотына енгізбейміз: нақты eval қабылдау шектерін орындамады және 20 ережелік baseline-нан нашар болды. Қолданыста baseline қалады. AI нұсқасы промпт немесе модель өзгертіліп, дәл сол eval-жинақта барлық шек орындалғаннан кейін ғана қайта қаралады. Бұл шешім дерек құпиялылығын бағаға айырбастамайды: сыртқы API тек бөлек құпиялылық бағалауынан кейін қаралады.

## Қабылдау шарты

Пилотқа дейін macro F1 ≥ 0,85, әр санат F1 ≥ 0,75 және `SAFETY recall` ≥ 0,90 болуы керек. Пилотта бірінші дұрыс бағыттау ≥ 90%, операторлық түзету ≤ 10% және медианалық бағыттау уақыты baseline-нан кемінде 40% төмен болуы тиіс.

## Салдар

**Оң:** сапасы жеткіліксіз функция пайдаланушыға әсер етпейді; baseline сақталады; шикі нәтижелерді қайта тексеруге болады.  
**Теріс:** күтілген уақыт үнемі әзірге алынбайды; модель/промпт өзгерген сайын толық eval қайта іске қосылады.

## Қайта қарау және тоқтату критерийі

500 өтініштен кейін немесе бір айдан соң шешім қайта қаралады. `SAFETY recall < 0,90`, операторлық түзету `> 10%`, дербес деректің сыртқа шығуы немесе айлық өзіндік құн API нұсқасынан тұрақты жоғары болуы — пилотты тоқтату триггері.
